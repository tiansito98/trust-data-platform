# Pendientes a resolver

Carpeta de **bugs y mejoras conocidas que aún no se han atacado**. Cada archivo
documenta uno o varios pendientes con el mismo formato: **síntoma / causa raíz /
alcance medido / fix propuesto / cómo validar**.

Cuando un pendiente se resuelve, marcarlo como hecho dentro de su archivo (o
moverlo a la sección "Ya hecho") en vez de borrarlo, para no perder el contexto.
